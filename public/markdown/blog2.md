## What is Markdown?

Markdown is a lightweight markup language that you can use to add formatting elements to plaintext text documents. It's widely used for:

- Writing documentation
- Creating readme files
- Formatting messages in online discussion forums

### Basic Syntax

Here are some basic syntax examples:

- **Bold**: `**bold text**` results in **bold text**
- *Italic*: `*italic text*` results in *italic text*
- `Code`: Use backticks for inline code like `console.log('Hello World')`

[Learn more about Markdown](https://www.markdownguide.org/)
